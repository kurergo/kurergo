Лучший сервис для курьера — тот, который подходит по доступности заказов, расходам и условиям именно в его городе. Универсальный рейтинг без одинаковых часов, транспорта и способа оформления вводит в заблуждение.

## Карточка сравнения двух предложений

| Пункт | Что записать для каждого сервиса |
| --- | --- |
| Оформление | Прямое подключение, парк или курьерская служба; сторона договора |
| График | Доступные часы, минимальная длительность, отмена слота |
| Оплата | Начисления за заказ, доплаты, условия бонусов |
| Выплаты | Первая дата, периодичность, комиссия за вывод |
| Затраты | Аренда, залог, транспорт, удержания |
| Поддержка | Канал связи при проблеме с активным заказом |
| Завершение | Возврат оборудования и окончательный расчёт |

## Как сравнить фактический результат

Сравнивайте похожие дни и часы в одном районе. Сохраните отчёты, уберите разовые бонусы за подключение и посчитайте остаток за всё затраченное время. Отдельно оцените задержки выдачи и удобство обращения в поддержку.

Не переносите отзыв автокурьера на пешую доставку. Не складывайте доходы двух сервисов так, будто одни и те же часы можно отработать дважды.

## Что означает «лучше» для вас

Для студента решающим может быть короткий вечерний выход, для владельца автомобиля — остаток после пробега, для новичка — понятные инструкции. Выберите критерий до сравнения рекламных сумм.
